# Images
Place your own licensed university images here.
Suggested files:
- campus-hero.jpg — hero banner
- university-logo.svg — official logo
- advisor-default.jpg — advisor placeholder

The current UI deliberately uses a visible placeholder in the hero. To insert the image, replace the `.image-slot` content in the `landing()` function inside `assets/js/app.js` with an `<img>` element pointing to `assets/images/campus-hero.jpg`, and add descriptive alt text.
